# Changelog

## 1.0.0-preview.1 — 2026-10-26

- Added a .NET 10 application alongside the preserved upstream source.
- Added modern password/Guard, mobile approval and QR authentication.
- Added protected saved sessions, account isolation and a local dashboard/CLI.
- Added owned-game selection, preferred display ordering, exclusions and rotation.
- Added schedules, estimated hour targets, statistics and AFK reply controls.
- Added session health checks, worker recovery and startup/service installers.
- Added diagnostics, checksummed packaging, update staging and rollback.
- Added automated rule, storage, security and API checks, plus opt-in live tests.
- Added the Windows desktop window, tray controls, and startup directly in the tray.
- Fixed aborted dashboard operations and repeated cleanup during Windows shutdown.
- Added opt-in incoming friend-request acceptance and request filtering/retry tests.
- Added the complete tutorial, troubleshooting guide, demo screenshots, and upstream contributor credits.

Read the feature matrix for current verification limits. This is a preview release; implemented features and live-verified paths are listed separately.
