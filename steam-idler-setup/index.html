How to set up a Steam game idler

Install HourBoostr on a computer or VPS you control. The public preview comes with a local dashboard for sign-in, game selection, and connection status.

Install on Windows or Linux

  1. Open the GitHub release and choose the ZIP for your operating system and processor.
  2. On Windows, extract it and open HourBoostr.Desktop.exe. On Linux, follow the Linux and VPS tutorial to start and pair the dashboard.
  3. Add a Steam account in the local dashboard and complete Steam Guard when prompted.
  4. Choose a game you own from the game library. Use the dashboard to start or pause the session and check its status.

Fix Steam sign-in problems

  • Use your Steam login name. It can differ from your public profile name.
  • Complete Steam Guard in the local app. Keep passwords and codes out of issue reports.
  • If Steam rejects a saved session, forget it in HourBoostr and sign in again. See the project troubleshooting guide for connection errors.

Check whether Steam credited playtime

Confirm the dashboard shows the account connected and the game selected. Start with one owned game when diagnosing a problem. Compare the local estimate with Steam-reported minutes. Valve prohibits automation that inflates playtime, so read its terms before using the app. Steam Subscriber Agreement.
