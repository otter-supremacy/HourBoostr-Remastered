# Screenshot provenance

These PNGs were captured from the real dashboard in a browser at desktop width. `scripts/screenshots-demo.py` supplied illustrative account, library, activity, and settings data.

They are interface previews, not evidence of a live Steam session or credited playtime. No real account IDs, credentials, tokens, QR challenges, chat messages, or library statistics appear in these images. See the feature matrix for actual validation status.

To reproduce, start `python scripts/screenshots-demo.py`, open `http://127.0.0.1:3244`, and capture the named views.
